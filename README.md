# Nonparametric Classification for Spatial Functional Data under Random Censoring

## Overview

This repository contains the R implementation developed during my Master's thesis in Applied Mathematics (Probability and Statistics).

The objective is to study nonparametric classification methods for spatial functional data under random censoring using Monte Carlo simulations.

## Research topics

- Functional Data Analysis
- Spatial Statistics
- Nonparametric Classification
- Random Censoring
- Monte Carlo Simulation

```

```
